# Revenue Model

Owned Systems Kit is open source. 10x Associates earns revenue through audits, implementation sprints, training, deployment support, custom templates, and future support for self-hosted control planes.

The method should be inspectable. The implementation help is paid.

## What is open source

- CLI tool (`osk`)
- JSON schemas for system records, workflows, dependencies, review gates, evidence, and exit plans
- Markdown and YAML templates (00-09)
- Example projects
- Evidence chain format specification
- Documentation

License: Apache-2.0.

## What is paid

- **AI Systems Audit** — map existing AI usage, tools, risks, and vendor dependencies
- **Owned Workflow Sprint** — prototype and document one high-value AI workflow
- **Evidence Chain Setup** — create audit-ready documentation around AI implementation
- **Internal Knowledge System** — turn scattered knowledge into a documented system
- **Human-in-the-Loop Agent Workflow** — design AI-assisted workflows with human approval
- **Training** — teach teams to operate and maintain their systems
- **Deployment support** — integrate with existing infrastructure
- **Custom templates** — adapt templates for specific industries or regulations
- **Retainers** — ongoing governance support

## Why this model

Ownership should be inspectable. If you cannot read the schemas, export the evidence records, and fork the method, you do not truly own the system.

We earn revenue through expertise and support, not by hiding the method. When we do our job properly, clients do not need us again.
