# Method

Owned Systems Kit follows a five-phase delivery method: Map, Prototype, Verify, Document, Transfer.

## Map

Understand the current state: tools, workflows, data flows, dependencies, and decision points. Before building anything, inventory what exists.

## Prototype

Build the smallest working version with human approval gates and provider abstraction from day one. Do not bolt on governance later.

## Verify

Test against real scenarios. Identify failure modes, edge cases, and governance gaps. Run the evidence chain. Check that human review gates work as designed.

## Document

Produce the complete documentation package: system register, workflow maps, dependency inventories, data boundary maps, prompt registers, review gate definitions, evaluation checklists, runbooks, maintenance plans, and exit plans.

## Transfer

Hand over with training and a clear path to operational independence. The documentation package lives in the client's repository. The exit plan is a standard deliverable.
