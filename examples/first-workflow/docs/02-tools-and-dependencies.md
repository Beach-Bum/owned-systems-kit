# Tools and Dependencies

## Dependencies

| Name | Type | Provider | Purpose | Cost | Switching cost | Alternative | Tested? |
|------|------|----------|---------|------|---------------|-------------|---------|
| Claude 3.5 Sonnet | model | Anthropic | Classify, summarize, draft replies | Pay per token | Low | GPT-4o, Gemini, local model | no |
| Shared email inbox | service | Google Workspace | Receive and send customer emails | Included in workspace plan | Medium | Microsoft 365, Fastmail | n/a |
| CRM | service | HubSpot Free | Customer history lookup | Free tier | Medium | Spreadsheet, Notion | n/a |

## License terms

- **Anthropic API:** Pay-per-use. Data is not used for training on the current API terms. Review terms quarterly.
- **Google Workspace:** Standard business license. Email data stored in Google infrastructure.
- **HubSpot Free:** Free tier. Customer records stored in HubSpot cloud. Export available as CSV.

## Data handling

- Customer inquiry text is sent to Anthropic API for classification and reply drafting. No customer payment data is included in API calls.
- Draft replies are generated by the API and returned to the team for review. They are not stored by Anthropic beyond the API request.
- Evidence records are stored locally in the team's repository.
